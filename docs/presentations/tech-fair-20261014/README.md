## 기술 설명을 강화한 지점

- **4장 시스템 구조도:** Excel 입력, 원문 DB, LLM 정리·번역, 키워드·벡터 색인, Clef 판단, 답변·원문 검사, 사용자 화면의 연결을 보여줍니다.
- **5장 기본 RAG 비교:** 자료 단위, 후보 순서, 설비·부품 관계, 답변 확인과 반복 운영을 비교합니다. 비교용 기본 구성은 재정렬과 원문 관계 보완을 제외한 것으로 정의했습니다.
- **6장 Clef 구조와 실측:** 질문과 후보 원문을 함께 읽고 허용 선택지의 점수를 얻는 과정을 표시합니다. 첫 정답 5/8에서 8/8, 상위 3개 포함 8/8 유지로 확인한 효과를 구분합니다.
- **7장 관계 그래프:** 같은 CS의 구동벨트·회전척 상세를 나누고, 공통 설비·모듈만 화면에서 한 번 표시합니다. 원문 관계 보기와 검색 후보 보완의 역할을 구분합니다.
- **8장 원문 근거:** 작업2의 실제 조치 셀과 그 기록이 뒷받침하는 설명 범위를 나란히 보여줍니다.

한글은 맑은 고딕, 영문·숫자는 Times New Roman으로 지정했습니다. 구조도·관계도·표와 차트는 PowerPoint 개체로 편집할 수 있습니다. 별첨은 본문 10장과 분리한 파일입니다. 발표자 노트에는 원고와 출처를 넣었습니다. [이전 발표 자료](../tech-fair-20261013/README.md)는 보존합니다.

## 근거와 한계

[Clef 대조 보고서](../../Clef-발표-조건비교-20261014.md)는 기존 개발 질문 중 한 유형의 8개 전체를 같은 후보에서 실제 Mac MLX GPU로 처리한 결과입니다. 정답 라벨은 모델에 전달하지 않았고, 결과를 독립 재계산했습니다. 최종 답변 LLM은 호출하지 않았습니다. 후보 순서가 좋아진 결과를 현장 정답률이나 조치 성공률로 확대하지 않습니다. 모델 적재를 포함한 호출 시간은 29.5~35.9초이므로 속도 향상 주장도 하지 않습니다.

관계 검색의 32/34에서 34/34는 2,000 합성 상세의 별도 평가입니다. 그래프 표시 자체의 효과를 측정한 수치가 아닙니다. 작업 복구 14/14, 동시 처리 7/7은 Mac·모의 모델 기능 검사이며 Windows 실제 사용자 부하를 증명하지 않습니다.

공개 원천 모델·재정렬 자체를 새 발명으로 표현하지 않았습니다. 공개 가능한 양산 성과·절감액·특허 출원등록·선진사 대비 우위는 확인하지 못했습니다. 실제 조치 판단은 담당자가 원문과 현재 조건을 확인해 수행합니다.

## 확인과 제출 준비

본문과 별첨 16장을 렌더링해 확인했고, 최종 PPTX를 다시 불러와 전체 페이지를 재렌더링했습니다. 글꼴 지정·표와 차트·슬라이드 수·노트·근거 수치·파일 구조를 검사했습니다. 프로그램과 운영 DB는 변경하지 않았습니다.

9분은 발표 배정이며 실제 낭독 측정값은 아닙니다. 발표자가 리허설로 10분 이내를 확인하고, 제출 Windows PC의 PowerPoint에서 글꼴과 배치를 확인해야 합니다. 이 개정판의 Windows PowerPoint 실기기 표시·편집·저장 검사는 하지 않았습니다. AI 분과 별도 공지와 별첨 제출 방식이 확정되면 규정에 맞춰 제출합니다.
