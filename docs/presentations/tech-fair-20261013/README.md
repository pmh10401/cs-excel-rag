한글은 맑은 고딕, 영문은 Times New Roman으로 지정했습니다. 각 슬라이드의 발표자 노트에도 원고와 근거 링크가 있습니다. 본문 4장의 흐름도, 비교 표와 검색 차트는 PowerPoint 개체로 편집할 수 있습니다. 별첨은 10장 제한의 본문과 분리했으며 정규 발표에서는 필요할 때만 참조합니다.

## 자료를 해석할 때의 범위

- 검색 비교는 10만 건의 합성 자료와 고정 개발 질문 50개를 사용했습니다. 정답이 있는 44문항에서 첫 정답은 키워드 28건, Qwen 결합 39건, 현재 EmbeddingGemma 2 결합 35건입니다. 현장 정확도나 최종 답변 품질을 측정한 결과는 아닙니다.
- 작업 복구 14건과 동시 처리 7건은 Mac·모의 모델의 기능 검사입니다. 실제 Windows DRM 및 GPT-OSS 120B 부하는 별도 확인이 필요합니다.
- 원문과 다른 상세를 섞지 않도록 구성한 업무 특화 구조를 설명합니다. 경쟁사 대비 우위, 특허 출원·등록, 양산 효과나 비용 절감은 확인 자료가 없어 성과로 제시하지 않았습니다.
- 첨부 화면은 가상 자료·모의 모델의 검사 화면입니다. 화면의 시간·건수는 실제 모델 성능이나 업무 효과를 뜻하지 않습니다.

## 확인과 제출 준비

모든 16장 렌더링을 확인했고, PPTX 구조·글꼴 지정·발표자 노트·지표와 원자료의 일치를 검사했습니다. Mac PowerPoint에서 본문 표지·흐름도·차트를 열어 표시를 확인했습니다. 프로그램 코드와 운영 데이터는 변경하지 않았습니다.

제출 전에 발표자가 실제로 낭독하여 10분 이내인지 확인하고, 제출 PC에서 두 글꼴과 화면 배치를 확인하세요. 9분은 배정 시간이며 실측 시간이 아닙니다. AI 분과 별도 공지와 별첨 제출 방식이 확정되면 해당 규정에 맞춰 제출하면 됩니다.
