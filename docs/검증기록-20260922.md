

## LM Studio 실제 번역 확인

Mac에서 이미 로드된 `openai/gpt-oss-20b`를 `high` 추론으로 호출했습니다. 창작한 중국어 현상·조치 두 셀의 한국어 번역이 정상 종료됐으며, 숫자·중국어 단위와 원문을 보존하는 검사도 통과했습니다. 이 호출의 입력은 645토큰, 출력은 추론 포함 1,563토큰, 소요 시간은 약 31.4초였습니다. 요청 출력 상한은 6,500토큰이며 사용자 설정 파일은 바꾸지 않았습니다.

앞선 2행 시험에서는 중국어를 포함한 한 행의 응답이 잘렸고 다른 영어 행은 성공했습니다. 출력 상한과 보수적인 입력 예약량이 실제 요청에 반영되는 것을 확인했습니다. 이후 출력 상한 6,500, 서버 문맥 기본값을 사용한 2행 시험은 한국어 번역·단위 오류 보정·채택·벡터 생성을 지나 답변 단계까지 도달했지만, 최종 답변이 잘려 실패했습니다. 전체 실모델 흐름의 성공으로 기록하지 않습니다. 현재 로드된 모델의 문맥 길이는 8,192토큰이었습니다. 성공한 단일 호출이나 모의 회귀 검사를 전체 파일 번역의 품질·성공률로 일반화하지 않습니다.
