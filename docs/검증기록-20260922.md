## 자동 검사

프로젝트 루트에서 실행한 명령은 다음과 같습니다. 모델 서버를 호출하지 않으며 시험용 데이터와 모의 응답을 사용합니다.

```sh
.venv/bin/python windows-demo/test_demo.py
.venv/bin/python package_windows.py
```

전체 자동 검사는 종료 코드 0, `PASS:` 출력 37개로 완료됐습니다. PASS 출력 개수는 검사 함수나 개별 질문의 개수가 아닙니다. 누적 등록, 중복 재사용, 출처 충돌 차단, 트랜잭션 되돌리기, 파일 삭제 후 UI·CLI·야간 처리와 파일 DB 연결 종료를 포함합니다. 직접 재현하려면 다음 명령을 사용할 수 있습니다.

```sh
.venv/bin/python -m tests.test_incremental
```

배포 검사는 압축을 임시 폴더에 풀고 전체 오프라인 검사, 일반·CS 검색, 평가 도구 도움말, 메뉴 종료를 실행했습니다. `.bat` 파일 3개의 구성과 CRLF 줄바꿈도 확인했습니다.

## 브라우저 확인

Mac의 Playwright에서 1440×1000 및 390×844 화면을 확인했습니다. 시험용 DB로 다음 순서를 실행했고 콘솔 오류가 없었습니다.

1. 첫 번째 Excel의 접수 1건을 등록한 뒤 Excel을 삭제했습니다.
2. DB에 저장된 원문을 대상으로 다듬기를 수행했습니다.
3. 두 번째 Excel의 접수 1건을 추가하고 이 파일도 삭제했습니다.
4. 질문 화면에서 두 건을 합한 누적 건수를 확인했습니다.

이 검증은 시험용 자료와 모의 모델 응답을 사용했습니다. 원문 등록 후 파일에 의존하지 않는 흐름을 확인했으며, 실제 LLM의 답변 정확도나 실제 DRM 제품을 검증한 결과는 아닙니다.
