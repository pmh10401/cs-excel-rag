### 개선·악화·동률과 순서 민감도

- H→G: 개선 7, 악화 1, 동률 16 / 공통 24. 전체 질문은 selection_changes.csv.
- H→HC: 개선 6, 악화 0, 동률 18 / 공통 24. 전체 질문은 selection_changes.csv.
- 후보 순서 추가시험: 원래 첫 ID 유지 10/12회. 대상6질문의 추가배치2개이며 독립 표본12개가 아니다. 직접적합 유지/악화와 fallback은 order_sensitivity.csv.
- 대표 개선·악화·동률은 각 유형에서 질문 ID 사전순 첫 사례로 선정한다. 없는 유형은 null로 보존한다. 전체 원문·출력의 case_packets.md는 로컬에 보존한다. 공개 합성 원문·질문은 synthetic-data.json, 순위는 ranking-results.json에 있다. LLM 응답 원문은 게시하지 않는다.

N은 원문 전용 BM25·필드 필터, V는 벡터 진단, H는 현재 결합 검색, G는 기존 DEV에서 선택된 Qwen4B, HC는 H의 동일 후보 재정렬이다. 공식/수동 사전이 없어 사전 보강 비AI 대안은 미평가다. H와 HC의 Hit@5는 같아야 한다. G는 상주 묶음 실행이며 HC의 요청별 적재 비용과 같은 속도 축이 아니다. 표의 모순은 명시된 대조상대 기록을 첫 번째로 선택한 수이며 모든 의미 모순 탐지가 아니다. 다른 설비·대상 선택은 직접적합 실패에 포함된다.

근거 없음6과 정확조회6은 summary.csv와 exact_regressions.json에 별도 표시했다. 집계값도 원문 접수 식별자로 대조한다. Clef 상대 점수는 정답/성공 확률이 아니다. 정확조회 우회는 Clef의 의미 이해 성공으로 세지 않는다. 사전 일괄 임베딩에는 V 진단용 정확조회6도 포함되며, H/HC 정확 조회가 모델을 사용했다는 뜻이 아니다.
