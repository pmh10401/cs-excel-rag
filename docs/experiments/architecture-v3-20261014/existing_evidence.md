# E0 기존 증거

이번 재현 모델 실행이 아니라 저장된 원시 ID·원문 제목·고정 매핑의 재계산이다. 기존 bool 값 합계를 라벨 독립 검증으로 부르지 않는다.

- keyword: 첫 적합 28/44, 현상만 25/41.
- qwen_hybrid: 첫 적합 39/44, 현상만 36/41.
- gemma2_hybrid: 첫 적합 35/44, 현상만 32/41.

- Clef 기존8: 템플릿 기준 첫 적합 5/8→8/8; 상위3 포함 8/8→8/8.
- 일부 원문에는 질문의 정상/비교 조건이 명시되지 않았다. 과거 템플릿 정답과 모든 필수 조건의 원문 지지를 구분한다. 최종 답변 미평가.
- 당시 적재 포함29.516~35.853초와 순수추론5.073~7.375초는 과거 보고 수치이며 이번 응답시간이 아니다.

- 관계 보완의 과거 보고32/34→34/34는 다른 자료·질문이다. 원시 group별 재계산은 JSON에 있으며 분모와 보호 조건을 확인하지 않고 합치지 않는다.
- 기존 Qwen 결합이 Gemma2 결합보다 나았던 결과를 함께 제시한다. 약한 검색의 약점을 선택 단계가 보완했을 가능성을 배제하지 않는다.
- 이전 큰 평가의 일부 결과·실패·비용은 보존했으며 신규36과 분모를 합치지 않는다.
