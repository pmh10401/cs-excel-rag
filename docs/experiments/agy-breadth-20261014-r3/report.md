## 비용과 해석

첫 CLI 시도의 RAG 메시지 지문이 같은 쌍은 동일한 선택 근거·지시문을 받은 경우다. 그래도 결과가 다르면 후보 수만의 인과 효과로 돌릴 수 없다. 지문은 제공자의 숨은 내부 문맥까지 동일함을 증명하지 않는다. 실패도 포함한 공통 CLI 진입 쌍만 세며 미실행은 별도다.

위 답변 단계 시간은 실패를 포함하고, 검색·후속 주소 해석·GPU 재정렬·브라우저 대기·운영 모델 교대를 포함하지 않는다. p95는 정렬된71개 중 floor(.95×70) 위치를 사용한다. SQL·재확인처럼 모델을 쓰지 않은 경로와의 중앙값도 원본CSV에 별도 보존했다. 실제 전체 사용자 응답 속도나 Windows 성능으로 발표할 수 없다. 이 실행에서는249개 답변 CLI가 각각 한 번만 호출됐고 보정 호출은0회였다. 규칙 검사 통과237건은 답변 제공208건과 근거 부족29건의 합이며 의미 정답률이 아니다.

코호트 밖 연결·DEV 진단의 알려진 비용은 `preflight-costs.json`에 별도로 남긴다. 초기 단독 실행 일부는 정확한CLI wall이 없으며, 시간 제한 뒤 원격 턴 취소 여부와 원격 장치 메모리·최종 과금 비용도 확인하지 못했다. 따라서 빠짐없는 전체 원격 비용을 측정했다고 주장하지 않는다.

판단: 이번 합성 자료에서는 후보 수를 늘릴 강한 근거나 답변 의미 품질의 확정적인 향상을 얻지 못했다. 운영 설정을 유지한다. 다음 독립 평가를 설계할 때는 다국어 후보 누락, 모호한 예정 문구, 직접적인 설비명이 없는 질문, 의미 판정 범위를 먼저 보완하고 새 자료·라벨을 추론 전에 다시 고정해야 한다. 이번 TEST를 수정해 새 검증으로 발표하지 않는다.

## 분석 이력의 한계

R3 재개 전 GPU TEST 순위는 이미 확인했다. 모델·원문·질문·프롬프트·후보·라벨은 바꾸지 않았고, DEV 관측에 따라 시간·병렬·실패 보존만 조정했다. 실행 중 후처리 도구의 비식별화·비용 합산·재검산을 보완했으므로 모든 분석 코드까지 TEST 이전에 완성한 독립 검증이라고 주장하지 않는다. 자세한 이력은 [audit](audit.md)에 기록했다.
