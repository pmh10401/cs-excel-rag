# 발표에 사용할 근거 · 2026-10-15 KST

## 사용할 수 있는 문장

- 질문 범위를10유형·신규200문항으로 확대하고 DEV40·기존회귀24를 분리했다. 창작 합성/실버 평가이며 TEST는20하드웨어 군집이다.
- 별도2998상세에서 같은 검색 목록의 후보5·10·20건을 실제 Mac MLX GPU로 재정렬했다. 실제576회·보호 경로 우회216기록을 구분했다.
- 실제 재정렬 양성120문항의 첫 기대ID는113·115·115건이었다. 정확 조회20문항을 포함하면133·135·135/140이다. 후보 확대의 작은 차이는 불확실하다.
- TEST80질문의 답변 흐름을 세 구성으로 비교했다. 검사 후 제공61·57·60/80, 오류2·7·4/80이었다. 답변 제공은 의미 정답을 뜻하지 않는다.
- 전체280흐름은 기록했지만 실패를 보존해 실행 상태는interrupted/complete=false이다. 실패를 성공으로 재분류하거나 무한 재실행하지 않았다.
- 후보20의 GPU 순수 계산 중앙12.215초는 후보5의4.362초보다 길었다. 적재·답변·운영 교대를 포함한 전체 서비스 속도와 다르다.
