# 누적 Excel 새 양식과 같은 CS의 상세 행

기준일: 2026-09-29 · 출처: 이 대화의 사용자 요청과 확인 답변을 요약한 기록이며 전체 대화록은 아닙니다.

- 시트: `19~26년 누적_2600831` → `19~26년 누적_260925`.
- 열: `Site` → `SITE`, `불량발생월` → `불량발생년월`.
- 한 CS에 여러 부품 문제가 있고 7개 구분 항목이 다를 수 있으며, 완전히 같은 행도 반복될 수 있음.
- 확인 질문에 대한 사용자 답변: **“내용이 다른 행은 별도 상세 기록으로 보관”**. 7개 항목이 같아도 현상·원인·조치가 다르면 별도 보관.

구현은 전체 셀 값·자료형·표시 형식을 비교하고 동일 입력만 재사용합니다. 파일·행·열 위치는 내용 비교에서 제외하며 처음 보관한 원문 위치를 유지합니다. 최신 행을 추정하여 이전 행을 삭제하거나 덮어쓰지 않습니다. CSList의 기존 갱신 정책은 그대로입니다.

근거: [양식 정의](../../ragkit/input_formats.py), [상세 ID·원문 읽기](../../ragkit/records.py), [기존 DB 재사용](../../ragkit/storage.py), [변환 캐시](../../ragkit/source_cache.py), [합성 상세 행 검사](../../tests/test_history_input.py).

검증 범위: 합성 Excel, 모의 모델, Excel 연결 대역으로 신·구 양식·완전 중복·부품 및 내용 차이·타입 차이·순서 변경·검토·인용·접수 집계를 검사합니다. 실제 사용자 Excel, Windows DRM 실기기, 실제 답변 모델 품질은 미확인입니다. 운영 DB·설정과 기존 모델 실험 결과를 수정하지 않았습니다.
