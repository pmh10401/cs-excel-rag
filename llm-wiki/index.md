```mermaid
flowchart LR
    S[대화 요구사항과 버전이 고정된 코드·문서] --> W[주제별 개발 위키]
    W --> D[설계 결정과 검증 한계 확인]
    D --> N[새 개발·검증 결과]
    N --> U[출처 추가와 관련 페이지 갱신]
    U --> W
```

**상태 읽는 법:** ‘현재 기능’은 기준 버전의 동작, ‘과거 검증’은 해당 날짜·장치·표본의 기록, ‘제안’은 아직 제품에 넣지 않은 방향입니다. 자동 검사를 통과했다는 사실과 실제 업무에서 정확한 답변을 한다는 판단은 구분합니다.
