# 이 위키를 갱신하는 방법

기준일: 2026-09-29. 상위 저장소의 작업·보안·Git 규칙을 따른다.

- 먼저 [목차](index.md)와 관련 주제 페이지를 읽는다. 같은 내용을 새 페이지에 반복하기보다 기존 페이지를 갱신한다.
- `raw/`는 날짜가 붙은 출처 기록이다. 기존 기록을 고치지 않고 정정·추가 자료를 새 기록으로 남긴다. 대화 요약은 원문 대화록이 아니라는 점을 표시한다.
- 주장에는 저장소 문서·코드 또는 원출처를 연결한다. 최초 기준 버전과 SHA-256은 [출처 목록](raw/2026-09-29-출처목록.md)에 있다. 다른 버전의 결과를 현재 성능으로 바꾸어 쓰지 않는다.
- 현재 기능, 과거 검증, 사용자 요구, 제안, 미확인을 구분한다. 서로 다른 표본·모델·장치의 지표를 하나의 정답률로 합치지 않는다.
- 새 자료가 기존 설명과 충돌하면 원인을 확인하고 해당 페이지의 상태·기준일을 수정한다. 과거 결과 자체를 덮어쓰거나 실패를 지우지 않는다.
- 실제 Excel·운영 DB·개인 설정·인증 정보·원시 LLM 로그를 위키나 Git에 복사하지 않는다. 원문 셀은 제품 DB의 근거이며 개발 위키가 이를 대신하지 않는다.
- 갱신한 페이지의 관련 링크, `index.md`, `log.md`를 함께 점검한다. 제품 설명이 달라졌다면 README·전체 플로우·임원 보고서도 맞춘다.
- 완료 전에 상대 링크, 깨진 출처, 상태 충돌, 실험 수치의 분모, 미확인 사항을 확인한다. 문서 변경만으로 모델 실험이나 운영 데이터 처리를 시작하지 않는다.
- 이 파일은 위키를 편집할 때의 작업 지침이다. 자동 실행·주기 점검·RAG 연동을 설치하거나 보장하지 않는다.
